# 🧱 System Architecture

### Frontend

* React / Next.js
* Mobile responsive (or React Native for dedicated app)
* Role-based routing

### Backend

* Node.js / Express
* PostgreSQL
* Rule Engine module
* Event-based alert system
* Audit logging middleware

### Required Core Services

* Authentication service (JWT + RBAC)
* Time computation engine
* Alert engine
* PTO accrual engine
* Export service (CSV/API)
* Audit logging system
