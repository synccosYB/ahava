This is a focused one-file fix. Here's exactly what to change:
server/replit_integrations/auth/replitAuth.ts — lines 16–27
ts// BEFORE
cookie: {
  secure: true,
  sameSite: "none",
  maxAge: 24 * 60 * 60 * 1000,
  httpOnly: true,
}

// AFTER
const isProd = process.env.NODE_ENV === "production";

cookie: {
  secure: isProd,
  sameSite: isProd ? "none" : "lax",
  maxAge: 24 * 60 * 60 * 1000,
  httpOnly: true,
}
That's the entire fix for Task 1. secure: true tells the browser to only send the cookie over HTTPS — in local dev you're on HTTP, so the browser silently drops it, which is why you get a clean 200 on login immediately followed by a 401 on the next request.
