My Recommendations Before Development Starts
Add These Missing Hardening Items
1. Anti-Spoofing

Even Phase 1 should include:

Blink detection
Head turn
Motion prompt
Screen glare check

Without this, printed photos or phone screens could spoof clocks.

2. Device Trust Integration

Biometrics should only run on:

Registered kiosks
Approved devices
Paired hardware

Do not allow open-browser biometric enrollment from unmanaged devices without security controls.

3. Template Encryption

Store descriptors:

Encrypted at rest
Tenant isolated
Rotatable
Access logged
4. Confidence Score Governance

Admin settings should define:

Minimum threshold
Auto-fallback threshold
Manual review threshold
Forced PIN threshold

Example:

0.90 = auto approve

0.75–0.89 = low confidence + log
<0.75 = reject
5. Retention Policy

Must include:

Auto-delete after X inactive days
Delete immediately on termination
Delete on consent revoke
Legal hold override
