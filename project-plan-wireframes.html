Ahava Medical Center

Time & Attendance Management System — Complete Project Plan & Wireframe Specifications

Project Type: Full-Stack Web Application

Stack: Fullstack JavaScript (React + Express + PostgreSQL)

Primary Users: Employees, Managers, HR Administrators

Version: 1.0 - Initial Planning Phase

Date: March 2, 2026 (EST)

Executive Summary

A comprehensive time and attendance management system that enables employees to clock in/out, request time off, and view their attendance records. Managers can approve requests, run reports, and monitor team attendance. HR administrators have full system oversight with advanced reporting and configuration capabilities.

Core Objectives

  • Simplify Time Tracking: Provide an intuitive interface for employees to record work hours
  • Streamline Approvals: Enable managers to efficiently review and approve time-off requests
  • Enhance Visibility: Give all stakeholders real-time access to attendance data
  • Ensure Compliance: Maintain accurate records for payroll and regulatory requirements
  • Improve Productivity: Reduce administrative overhead through automation

User Roles & Permissions

1. Employee

  • Clock in/out for shifts
  • View personal attendance history
  • Submit time-off requests (vacation, sick leave, personal days)
  • View request status and approval history
  • Access personal time balance (PTO, sick days)

2. Manager

  • All employee capabilities
  • View team attendance in real-time
  • Approve/deny time-off requests from team members
  • Run team attendance reports
  • View team time-off calendar
  • Receive notifications for pending approvals

3. HR Administrator

  • All manager capabilities across all departments
  • Manage user accounts and role assignments
  • Configure time-off policies and accrual rules
  • Access company-wide attendance reports
  • Export data for payroll processing
  • System configuration and settings management

MVP Features (Phase 1)

  1. User Authentication with SSO
    • Secure login/logout functionality
    • Role-based access control (Employee, Manager, HR Admin)
    • Session management
  2. Clock In/Out System
    • One-click clock in/out button with timestamp
    • Visual indicator of current status (clocked in/out)
    • Automatic calculation of hours worked
    • Today's shift summary display
  3. Attendance History
    • Personal attendance record table with date, clock in/out times, total hours
    • Filter by date range
    • Sort by various columns
    • Weekly and monthly hour summaries
  4. Time-Off Request Management
    • Request form with date range picker, type selection, and notes
    • Visual calendar showing requested and approved time off
    • Status tracking (pending, approved, denied)
    • Request history table
  5. Manager Approval Dashboard
    • Pending requests queue with employee details
    • Quick approve/deny actions with optional comments
    • Team attendance overview
    • Notification badges for pending items
  6. Basic Reporting
    • Employee attendance report (personal)
    • Team attendance report (for managers)
    • Company-wide report (for HR)
    • Export to CSV functionality
  7. Responsive Dashboard Design
    • Clean, professional interface with Shadcn UI components
    • Mobile-responsive layout
    • Intuitive navigation with role-based menu items
    • Real-time status updates

Next Phase Features (Phase 2)

  1. Manual Time Entry Corrections
    • Employees request corrections for missed punches
    • Manager approval workflow for corrections
  2. Advanced Time-Off Policies
    • Automatic PTO accrual calculations
    • Multiple leave types with separate balances
    • Blackout date configuration
  3. Email Notifications
    • Request submission confirmations
    • Approval/denial notifications
    • Reminder emails for pending manager actions
  4. Enhanced Reporting & Analytics
    • Overtime tracking and alerts
    • Attendance trends and patterns
    • Custom report builder with filters
    • Scheduled report generation
  5. Department & Team Management
    • Hierarchical organization structure
    • Department-specific policies
    • Team calendar views

Security & Best Practices

  • Authentication: OAuth 2.0 / SSO
  • Authorization: Role-based access control on all endpoints
  • Data Privacy: Users only see authorized data
  • Session Security: Secure cookies, HTTPS only
  • Input Validation: Client and server-side validation
  • SQL Injection Prevention: Parameterized queries via Drizzle ORM
