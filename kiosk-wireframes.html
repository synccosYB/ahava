Overview

The Kiosk Clock-In System is a tablet-based shared station that allows employees to quickly clock in and out of their shifts. Unlike the personal web application, the kiosk is a dedicated device mounted at a fixed location in the facility. Employees identify themselves using a PIN code or name search, then tap to clock in or out. The kiosk is designed for fast, touch-friendly interaction with minimal steps.

Key Differences from the Web Application

  • Shared Device: No individual login/logout — employees identify via PIN or name search
  • Single Purpose: Clock in/out only — no PTO requests, timesheets, or reports
  • Touch Optimized: Large buttons, simple layout, designed for quick interactions
  • Auto-Reset: Returns to home screen after each use (configurable timeout)
  • Fixed Location: Registered to a specific location for verification
  • Offline Support: Queues punches locally if network connection drops

Kiosk User Flow

Home Screen → Employee Lookup (PIN or Name Search) → Clock Confirmation (Review & Tap) → Success Screen (Auto-reset after 5 seconds)

Kiosk Features & Requirements

Core Functionality

  • PIN Entry: 4-digit numeric PIN assigned to each employee
  • Name Search: Type-ahead search by first or last name
  • One-Tap Punch: Single button to clock in or out based on current status
  • Shift Summary: Shows total hours on clock-out confirmation
  • Auto-Reset: Returns to home screen after 5 seconds (configurable)
  • Idle Timeout: Returns to home if no interaction for 30 seconds

Device Management

  • Device Registration: Each kiosk tablet is registered to a specific location
  • Admin Lock: Kiosk mode prevents access to other apps on the tablet
  • Remote Configuration: Admins can update settings from the web dashboard
  • Health Monitoring: Dashboard shows kiosk online/offline status

Offline Support

  • Local Punch Queue: Punches stored locally when network is down
  • Auto-Sync: Queued punches automatically sync when connection restores
  • Offline Indicator: Visual warning shown to employees when offline
  • Employee Cache: PIN and name data cached locally for offline lookup

Security

  • PIN-Based Authentication: Simple but unique per employee
  • No Sensitive Data Displayed: Only name, department, and punch status shown
  • Auto-Logout: Screen resets quickly to prevent unauthorized access
  • Location Verification: Punches tagged with registered kiosk location
  • Audit Trail: All kiosk punches logged with device ID and timestamp

Hardware Requirements

Recommended Tablets

  • iPad (10th gen or newer)
  • Samsung Galaxy Tab A8 / A9
  • Any 10"+ Android tablet
  • Minimum 10" screen recommended

Accessories

  • Wall mount or desk stand
  • Continuous power supply (always plugged in)
  • Wi-Fi connection
  • Optional: Ethernet adapter for reliability

Kiosk Software

  • Guided Access (iPad) or Kiosk Mode (Android)
  • Progressive Web App (PWA) — runs in browser
  • No app store installation required
  • Auto-updates via web deployment
