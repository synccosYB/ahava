Executive Summary

A comprehensive time and attendance management system that enables employees to clock in/out, request time off, and view their attendance records. Managers can approve requests, run reports, and monitor team attendance. HR administrators have full system oversight with advanced reporting and configuration capabilities.

Core Objectives

  • Simplify Time Tracking: Provide an intuitive interface for employees to record work hours
  • Streamline Approvals: Enable managers to efficiently review and approve time-off requests
  • Enhance Visibility: Give all stakeholders real-time access to attendance data
  • Ensure Compliance: Maintain accurate records for payroll and regulatory requirements
  • Improve Productivity: Reduce administrative overhead through automation

User Roles & Permissions

1. Employee

  • Clock in/out for shifts
  • View personal attendance history
  • Submit time-off requests (vacation, sick leave, personal days)
  • View request status and approval history
  • Access personal time balance (PTO, sick days)

2. Manager

  • All employee capabilities
  • View team attendance in real-time
  • Approve/deny time-off requests from team members
  • Run team attendance reports
  • View team time-off calendar
  • Receive notifications for pending approvals

3. HR Administrator

  • All manager capabilities across all departments
  • Manage user accounts and role assignments
  • Configure time-off policies and accrual rules
  • Access company-wide attendance reports
  • Export data for payroll processing
  • System configuration and settings management

Tablet Kiosk Clock-In System

The Kiosk Clock-In System is a tablet-based shared station that allows employees to quickly clock in and out of their shifts. Unlike the personal web application, the kiosk is a dedicated device mounted at a fixed location in the facility. Employees identify themselves using fingerprint or face recognition, then confirm to clock in or out. The kiosk is designed for fast, touch-friendly interaction with minimal steps and maximum security against buddy punching.

Key Differences from the Web Application

  • Shared Device: No individual login/logout — employees identify via biometrics (fingerprint or face recognition)
  • Biometric-First: Fingerprint or face recognition is the primary identification method — prevents buddy punching (PINs can be shared between employees, biometrics cannot)
  • Fallback Search: If biometrics fail, employee can search by name, then must verify identity with fingerprint or face scan
  • Admin PIN Backup: Admin can assign a PIN per employee as a last-resort fallback only
  • Single Purpose: Clock in/out only — no PTO requests, timesheets, or reports
  • Touch Optimized: Large buttons, simple layout, designed for quick interactions
  • Auto-Reset: Returns to home screen after each use (configurable timeout)
  • Fixed Location: Registered to a specific location for verification
  • Offline Support: Queues punches locally if network connection drops

Authentication Priority

  1. Fingerprint Scan — Primary method. Employee places finger on sensor; system identifies them automatically.
  2. Face Recognition — Alternative biometric. Employee looks at the tablet camera; system identifies them.
  3. Name Search + Biometric Verification — If biometrics don't return a match, employee searches by name, then must verify with fingerprint or face scan.
  4. Admin-Assigned PIN — Last-resort fallback only. Admin creates the PIN; employee cannot choose or change it. Used only when biometric hardware is unavailable.

Kiosk User Flow

Home Screen → Biometric Scan (Fingerprint or Face) → Employee Identified → Clock Confirmation (Review & Tap) → Success Screen (Auto-reset after 5 seconds)

Fallback: Home Screen → Name Search → Biometric Verification → Clock Confirmation → Success Screen

Kiosk Features & Requirements

Core Functionality

  • Fingerprint Scan: Primary identification method — employee places finger on sensor, system identifies them automatically
  • Face Recognition: Alternative biometric method — employee looks at the tablet camera for identification
  • Name Search Fallback: Type-ahead search by first or last name, followed by biometric verification to confirm identity
  • Admin-Assigned PIN: Last-resort backup — admin creates PIN for employee; used only when biometric hardware is unavailable
  • One-Tap Punch: Single button to clock in or out based on current status
  • Shift Summary: Shows total hours on clock-out confirmation
  • Auto-Reset: Returns to home screen after 5 seconds (configurable)
  • Idle Timeout: Returns to home if no interaction for 30 seconds

Device Management

  • Device Registration: Each kiosk tablet is registered to a specific location
  • Admin Lock: Kiosk mode prevents access to other apps on the tablet
  • Remote Configuration: Admins can update settings from the web dashboard
  • Health Monitoring: Dashboard shows kiosk online/offline status

Offline Support

  • Local Punch Queue: Punches stored locally when network is down
  • Auto-Sync: Queued punches automatically sync when connection restores
  • Offline Indicator: Visual warning shown to employees when offline
  • Employee Cache: PIN and name data cached locally for offline lookup

Security

  • Biometric Authentication: Fingerprint and face recognition prevent buddy punching — unlike PINs, biometrics cannot be shared between employees
  • Two-Step Fallback: Name search alone is not enough — employee must also verify with biometrics after selecting their name
  • Admin-Controlled PINs: PINs are created and managed by administrators only, not by employees; used as last-resort backup
  • No Sensitive Data Displayed: Only name, department, and punch status shown
  • Auto-Logout: Screen resets quickly to prevent unauthorized access
  • Location Verification: Punches tagged with registered kiosk location
  • Audit Trail: All kiosk punches logged with device ID, biometric method used, and timestamp

Kiosk Hardware Requirements

Recommended Tablets

  • iPad (10th gen or newer)
  • Samsung Galaxy Tab A8 / A9
  • Any 10"+ Android tablet
  • Minimum 10" screen recommended

Accessories & Biometric Hardware

  • Wall mount or desk stand
  • Continuous power supply (always plugged in)
  • Wi-Fi connection
  • Optional: Ethernet adapter for reliability
  • USB fingerprint scanner (e.g., DigitalPersona, Futronic)
  • Front-facing camera for face recognition (built-in or external)

Kiosk Software

  • Guided Access (iPad) or Kiosk Mode (Android)
  • Progressive Web App (PWA) — runs in browser
  • No app store installation required
  • Auto-updates via web deployment

Security & Best Practices

  • Authentication: OAuth 2.0 / SSO
  • Authorization: Role-based access control on all endpoints
  • Data Privacy: Users only see authorized data
  • Session Security: Secure cookies, HTTPS only
  • Input Validation: Client and server-side validation
  • SQL Injection Prevention: Parameterized queries via Drizzle ORM
